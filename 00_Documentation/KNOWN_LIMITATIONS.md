# Known limitations and manuscript-facing checks

These are **not resolved** merely by packaging the scripts.

1. **No full independent execution**: The curation environment does not contain R or the required original UK Biobank/GWAS, eQTL, LD-score, LAVA and PLINK input resources. This archive was static-checked, not end-to-end re-executed. Do not claim independently reproduced results.
2. **T2D GWAS case/control metadata**: Step30a retains `GCST006867`, N=655666, cases=61714, controls=593952 (s=0.0941...). These are the values in the user's original script and are *not* silently replaced with published full-meta-analysis counts. Verify against the exact downloaded summary-statistics file and its per-variant N information before release.
3. **LAVA exploratory analysis**: The nominal local h2 threshold p<0.05 for both traits and subsequent tested-region corrections are in Step25b. The term *prespecified* in the manuscript must be supported by contemporaneous analysis documentation; otherwise call it an exploratory sensitivity analysis.
4. **Step29 vs Step29b**: Step29 includes the original MR and preliminary multivariable MR; the manuscript's MVMR coefficients should be taken from **Step29b** (additional global union LD-clumping). The historical Step29 MVMR estimates are not the final primary MVMR.
5. **Step26b**: A repair/recovery workflow, not a second independent primary analysis. Its two scripts should be interpreted as one recovery process.
6. **Early stages 01–06 and 08**: Original contemporaneous source scripts were not recovered. `REBUILD_steps_01_06_08.R` is explicitly a reconstruction and requires historical archived inputs/`reference_results` not distributed here. It must not be represented as the original historical source.
7. **Project paths**: Most original scripts use `~/胰腺`, `~/mr_tools`, specific LD references, and existing historical output folders. The original source has intentionally not been globally rewritten to avoid silently changing the analytical environment. Establish compatible paths or adapt and audit them before running on a new system. Step30a/30b additionally accept `PANCREAS_PROJECT_ROOT`.
8. **Cross-stage pipeline**: Earlier scripts search for historical run folders; this is an archived workflow, not an independent one-click workflow from raw data. Individual stages must be run after provisioning inputs and verifying which outputs they read.
9. **Figure/table code**: The historical manuscript-layout Step30 is not included as a statistical-analysis step. This submission bundle includes analytic code, but not a fully executable recipe for every figure and ESM page. The manuscript-figure assembly package is separate.
10. **Versioning**: Some scripts automatically install R dependencies from CRAN. Repository maintainers should replace unpinned installation with a recorded `renv.lock`/container environment and supply tested R, PLINK, LDSC, LAVA, 1000G EUR reference versions before declaring reproducibility on another platform.
11. **Public release**: Check the rights and terms for any upstream tools/reference panels. The package does not include individual-level UK Biobank data or large external GWAS reference assets. Repository DOI, software licence and final author credits have not been assigned.
